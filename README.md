# College Placement Management System

A web-based College Placement Management System developed using Python, Flask, MySQL, HTML, CSS and JavaScript.

## Features

- Student Registration and Login
- Recruiter Registration and Login
- Student Profile Management
- Recruiter Company Profile
- Job Posting and Management
- Job Search and Job Details
- Student Job Applications
- Application Status Tracking
- Shortlist, Reject and Select Candidates
- Interview Scheduling
- Interview Rescheduling
- Interview Cancellation
- Interview Completion
- Candidate Profile and Resume Viewing
- Student and Recruiter Dashboards
- MySQL Database Integration

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
